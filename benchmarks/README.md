# Benchmarks

This release exposes exactly two benchmark packages:

- `cdo_f1f15`: CDOBench F1-F15. F1-F14 use the bundled 20-agent matrices; F15 is the deterministic MASOIE-style WSN problem used during C8c training.
- `wsn_f1f5`: the five 16-node WSN localization evaluation problems.

No benchmark reads data outside this repository.
