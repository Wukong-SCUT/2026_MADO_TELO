# Algorithm package manifest

Included: E3aj MAPPO source, required local optimizer implementations, CDOBench and WSN benchmark interfaces/data, one pretrained checkpoint, portable dependencies, and algorithm configuration.

The package is intended to provide the implementation and its runnable defaults. Generated files are written under `outputs/`, which is runtime-only and ignored by Git.

The packaged CDO data are the 20-agent files required by the supported CDOBench entry; the packaged WSN data are the files required by the WSN entry.
